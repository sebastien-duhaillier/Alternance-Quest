# 🎮 Alternance Quest

## 🧩 Présentation

Alternance Quest est un mini jeu web interactif dans lequel le joueur incarne un candidat à la recherche d’une alternance en développement web.

Le joueur progresse à travers différents environnements en répondant à des questions techniques et professionnelles, jusqu’au boss final : le recruteur.
Mais ce n'est que le début ...
---

## 🎯 Objectifs

* Mettre en pratique JavaScript (logique, DOM, événements)
* Créer une expérience interactive simple
* Structurer un projet front-end propre
* Construire un projet portfolio original

---

## 🎮 Gameplay

* Progression par scènes (rue, transport, entreprise…)
* Chaque scène contient une question (QCM)
* Bonne réponse → progression
* Mauvaise réponse → pénalité ou nouvelle tentative
* Boss final : entretien d’embauche

---

## 🧠 Compétences utilisées

* JavaScript (logique, conditions, tableaux, objets)
* Manipulation du DOM
* Gestion des événements
* Structuration du code
* UX/UI simple
